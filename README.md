# เว็บไซต์ข้าวเหนียวมะม่วง ขนมไทยแสนอร่อย

## โครงสร้างโฟลเดอร์

```
mango-site/
├── index.html          โครงหน้าเว็บ (ปกติไม่ต้องแก้)
├── css/style.css       สี ฟอนต์ และการจัดวาง
├── js/app.js           โค้ดการทำงาน (ปกติไม่ต้องแก้)
├── data/content.js     ★ ข้อความและรายการรูปทั้งหมด แก้ที่นี่ที่เดียว
└── images/             ★ ไฟล์รูปภาพของคุณ
    ├── hero.jpg                รูปใหญ่หน้าแรก
    ├── history.jpg             รูปส่วนประวัติศาสตร์
    ├── ingredients/            sticky-rice.jpg, mango.jpg, coconut-milk.jpg,
    │                           sugar.jpg, salt.jpg, pandan.jpg, mung-beans.jpg
    ├── steps/                  step1.jpg ถึง step6.jpg
    ├── videos/                 ★ คลิปประกอบขั้นตอน step1.mp4 ถึง step6.mp4 (ไม่บังคับ)
    └── gallery/                g1.jpg ถึง g8.jpg
```

## วิธีเปิดเว็บ
ดับเบิลคลิก `index.html` (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์) ใช้ได้ทันที ไม่ต้องติดตั้งอะไร

## วิธีแก้ข้อความ
เปิด `data/content.js` ด้วย Notepad / TextEdit / VS Code (บันทึกเป็น UTF-8) แล้วแก้เฉพาะข้อความในเครื่องหมาย `'...'`
ห้ามลบเครื่องหมายคำพูด จุลภาค `,` หรือวงเล็บปีกกา `{ }` ถ้าข้อความมีเครื่องหมาย `'` ให้เขียนเป็น `\'`
บันทึกแล้วกดรีเฟรชหน้าเว็บ

## วิธีเปลี่ยนหรือเพิ่มรูป
1. **เปลี่ยนรูปเดิม:** วางไฟล์ใหม่ในโฟลเดอร์ `images` ให้ชื่อตรงกับด้านบน (เช่น `images/hero.jpg`) เว็บจะใช้รูปในโฟลเดอร์ก่อนเสมอ
2. **ถ้าไฟล์เป็นนามสกุลอื่น** (เช่น `.png`, `.webp`) ให้แก้ชื่อไฟล์ในบรรทัด `file:` ของรูปนั้นใน `data/content.js`
3. **เพิ่มรูปในแกลเลอรี่:** คัดลอกบล็อก `{ caption: ..., image: {...} },` ในหัวข้อ `GALLERY` แล้วแก้คำอธิบายกับชื่อไฟล์
4. ถ้าไม่พบไฟล์ในโฟลเดอร์ เว็บจะลองใช้ลิงก์ออนไลน์ (`online:`) และถ้ายังไม่ได้ จะแสดงภาพอีโมจิแทน หน้าเว็บจึงไม่มีรูปแตก
5. แนะนำให้ย่อรูปให้กว้างไม่เกิน 1600 พิกเซล เพื่อให้เว็บโหลดเร็ว

## วิธีใส่คลิปแทนรูปในขั้นตอนวิธีทำ
เปิด `data/content.js` ที่หัวข้อ `STEPS` แต่ละขั้นตอนมีบรรทัด `video:` อยู่แล้ว
- **คลิปจากไฟล์:** วางไฟล์ `.mp4` (แบบ H.264) ในโฟลเดอร์ `videos/` ตั้งชื่อ `step1.mp4` ถึง `step6.mp4` ก็จะแสดงแทนรูปของขั้นตอนนั้นทันที หรือตั้งชื่ออื่นแล้วแก้ในบรรทัด `video:`
- **คลิปจาก YouTube:** เพิ่มบรรทัด `youtube: 'https://youtu.be/รหัสวิดีโอ'` ในขั้นตอนนั้น (ถ้าใส่ จะใช้แทนไฟล์)
- **ถ้าไม่มีไฟล์คลิป** เว็บจะแสดงรูปของขั้นตอนนั้นตามปกติ ขั้นตอนไหนไม่อยากใช้คลิปก็ลบบรรทัด `video:` ออกได้
- รูปของขั้นตอน (`images/steps/stepN.jpg`) จะถูกใช้เป็นภาพปกของคลิปก่อนกดเล่น
- ดับเบิลคลิกที่การ์ดเพื่อขยายได้เหมือนเดิม (ดับเบิลคลิกบนตัวเล่นคลิปจะเป็นการเต็มจอของตัวเล่น) และเพลงประกอบจะหยุดให้เองเมื่อกดเล่นคลิป
- ไฟล์คลิปแนะนำไม่เกิน 50–100 MB ต่อคลิป ถ้าใหญ่กว่านั้นให้อัปขึ้น YouTube แล้วใช้ลิงก์แทน
